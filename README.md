# Ciclo 7 — Landing page

Landing page responsiva de arquitetura, engenharia e manutenção predial.

Site: https://aiinvente.github.io/ciclo7-landing-page/

## Publicação

Site estático em HTML, CSS e JavaScript, publicado pelo GitHub Pages a partir da branch `main`, pasta raiz. Não exige instalação nem etapa de compilação.

Inclui imagens otimizadas, fontes Lato locais, navegação responsiva, planos expansíveis, perguntas frequentes e carrossel de três imagens com transição a cada 20 segundos.

As alterações enviadas para `main` são publicadas automaticamente. A página está configurada para não ser indexada durante a aprovação.

## Créditos

Lato: licença em `assets/OFL-Lato.txt`. As imagens são ilustrativas. Os elementos de marca e o conteúdo pertencem aos respectivos titulares.
